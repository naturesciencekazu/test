Overview

GitHub Pages とは？

GitHub Pages は、GitHub が提供する無料の Web ホスティングサービスです。 HTML ファイルをアップロードするだけで、誰でもアクセスできる Web ページを公開できます。 独自ドメインの取得も不要で、username.github.io 形式の URL が自動で発行されます。

￥0 完全無料 サーバー費用もドメイン費用も不要。GitHub アカウントさえあれば始められます。
3 ステップで公開 HTML作成 → アップロード → Pages設定の 3 ステップだけ。難しい操作はありません。
AI コード不要 Claude（AI）に「HTML を作成して」と話しかけるだけで、プロ品質のページが完成します。

How To

3ステップで公開する

1

Step 1

HTML ファイルを作成する

  • 1 Claude（claude.ai）を開く ブラウザまたはデスクトップアプリどちらでも OK
  • 2 チャットに「自己紹介のホームページを作って。HTML で。」と入力して送信 ニックネーム・活動内容・リンクなどを一緒に伝えると、より個性的なページが生成されます
  • 3 Claude がファイルを自動生成するので、チャット内のファイルカードから index.html をダウンロード
💡 ポイント　ファイル名は必ず index.html にしてください。GitHub Pages はこのファイルを自動でトップページとして認識します。
2

Step 2

GitHub にファイルをアップロードする

  • 1 github.com でアカウントを作成またはログイン
  • 2 右上の「＋」→「New repository」で新しいリポジトリを作成 Visibility は必ず Public（公開）に設定してください
  • 3 空のリポジトリが表示されたら、ページ中央の「既存のファイルをアップロードして」という青いリンクをクリック 英語表示の場合は「uploading an existing file」
  • 4 index.html をドラッグ＆ドロップしてアップロード
  • 5 ページ下部の「Commit changes」ボタンをクリックして保存
💡 ポイント　リポジトリ名は後で URL の一部になります（例：「mypage」→ username.github.io/mypage）。わかりやすい名前にしておきましょう。
3

Step 3

GitHub Pages を有効化する

  • 1 リポジトリ上部のタブから「Settings（設定）」をクリック
  • 2 左サイドバーの「Pages」を選択
  • 3 Branch（ブランチ）を main ／ (root) に設定して「Save（保存）」をクリック
  • 4 数分後、同じ Pages 設定ページの上部に公開 URL が表示されます 反映に 2〜5 分かかる場合があります。ページを更新して確認してください
🎉 完成！　URL が表示されたらページの公開完了です。リンクをクリックして、自分のホームページを確認しましょう。

FAQ

よくある質問

GitHub アカウントの作り方は？ +
github.com にアクセスし「Sign up」からメールアドレスとパスワードを登録するだけです。無料プランで GitHub Pages を使うことができます。登録後にメール認証があるので、受信ボックスを確認してください。
ページを更新したいときはどうすれば良い？ +
Claude に「前回のHTMLをもとに〇〇を追加して」と伝えて新しい index.html を生成し、GitHub のリポジトリページから再びアップロードするだけです。同じファイル名でアップロードすると自動的に上書きされます。
アップロードした後、すぐにページが表示されない +
GitHub Pages の反映には通常 2〜5 分かかります。Settings → Pages を再度開くと公開 URL が表示されますが、リンクが有効になるまで少し待ってからアクセスしてみてください。ブラウザのキャッシュが残っている場合は Ctrl＋Shift＋R（Mac: Cmd＋Shift＋R）でキャッシュクリアを試してください。
リポジトリを Private にしたらページは消える？ +
無料プランでは、リポジトリを Private にすると GitHub Pages も非公開になります。ページを公開し続けるには、リポジトリを Public のままにしておくか、GitHub Pro（有料プラン）にアップグレードする必要があります。
画像や複数ファイルも使える？ +
はい。複数のファイルをまとめてアップロードすることもできます。ただし、Claude が生成するページはすべての CSS・画像・JavaScript を 1 つの HTML ファイルに埋め込む形式なので、基本的には index.html だけで完結します。
